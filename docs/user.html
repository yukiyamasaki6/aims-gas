入力手順

入力にはGoosleスプレッドシートを使用します

合同練習

※試合形式の合同練習の入力方法は 試合集計システム を参照してください

  1. 大阪公立大学アーチェリー部の目次シートを開く
  2. キャンパス別に合同練習入力用のスプレッドシートを開く
  3. 入力したい日付のシートを開く
  4. 出欠、射数、距離と点数を入力する

ノルマ練習

  1. 大阪公立大学アーチェリー部の目次シートを開く
  2. キャンパス別にノルマ練習入力用のスプレッドシートを開く
  3. 入力したい期間のシートを開く
  4. 入力様式に従って、上部に距離、中部に点数(近射は射数)or空白、下部に日付を入力する

点数申告フォーム

  1. 大阪公立大学アーチェリー部の目次シートを開く
  2. 点数申告フォームを開く
  3. フォームの指示に従って入力を行う

試合集計システム

  1. 大阪公立大学アーチェリー部の目次シートを開く
  2. 試合集計システムを開く
  3. 団体戦シートか個人戦シートを開く
  4. 試合を行う距離を入力する
  5. (団体戦のみ)勝敗の判定方法を選ぶ
  6. 立ち形式を選ぶ
  7. 試合形式を選択する
  8. 立ちに氏名を入力する
  9. 1エンド終了ごとに点数を入力する
終了後
  1. 結果保存シートの，対応するセルに「保存」を入力する
  2. 「保存」が消えたら保存完了

ユニフォーム貸出

  1. 大阪公立大学アーチェリー部を開く
  2. シートの選択からユニ管理シートを開く
  3. ユニフォームの貸出状態を更新する

閲覧手順

点数一覧

  1. 大阪公立大学アーチェリー部を開く
  2. シートの選択から点数一覧シートを開く
  3. フィルタの内容を組み替えて、欲しい情報を表示する
